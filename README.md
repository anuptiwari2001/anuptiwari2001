## Featured Projects

### [PID-Inspector](https://github.com/anuptiwari2001/PID-Inspector)
A local P&ID quality inspector that reads structured drawing data and reports tags, connections, and consistency findings without requiring a paid API or database.

### [PID-Consistency-Checker](https://github.com/anuptiwari2001/PID-Consistency-Checker)
A rule-based checker for P&ID consistency, helping identify unconnected nozzles, incomplete lines, orphaned instruments, and project-rule violations.

### [Pid-Comparison](https://github.com/anuptiwari2001/Pid-Comparison)
A vision-AI-assisted tool for comparing markup drawings with revised P&IDs and highlighting items that may not have been applied correctly.

### [pid-extraction-api](https://github.com/anuptiwari2001/pid-extraction-api)
An API-focused project exploring structured extraction of engineering data from P&IDs using OCR/VLM workflows and rule-based logic.

### [Hazop_App](https://github.com/anuptiwari2001/Hazop_App)
A HAZOP review project for analyzing P&ID PDFs and generating risk findings, annotated outputs, and structured engineering review material.
